# Overview

The main purpose of this fork is to make an enterprise version that is smaller and more lightweight.

- Target x64 processors
- Use BitLocker encryption for file storage
- No web server for remote view
- Local storage only
- Use the latest version of .NET
- Remove Deprecated packages
- Remove non-ecential functionality
- Load cameras from a config file
- All cameras must be RTSP type
- Cameras time stamp the video
- Needs to run as a service
